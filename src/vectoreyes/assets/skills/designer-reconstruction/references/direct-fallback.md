# Direct vectorEyes fallback

Use this only when MCP conversion fails internally and a local vectorEyes
installation and the actual source file are available. Record the MCP error;
do not interpret every server failure as a bad image. Do not hand-author SVG
paths or claim that a direct conversion creates a live drawing/version.

Use the installed drawing API so tracing and output policy match the MCP path.
Choose options from [the use-case presets](trace-presets.md). For genuinely
black-and-white artwork, this standalone process preserves fine details and
exports actual transparent path cutouts:

```python
from pathlib import Path
from types import SimpleNamespace
from vectoreyes.mcp_server import (
    DirectImageRef, TraceDrawingOptions, vectoreyes_trace_drawing, vectoreyes_get_drawing_artifact,
)

options = TraceDrawingOptions(
    max_sampling_colors=2,
    max_output_colors=2,
    allow_gradients=False,
    background_cutouts="subtract",
    refine="none",
    trace_level="subpixel",
    fit_strategy="progressive_allow_lines",
    min_region_fraction=0,
    min_region_size=1,
    max_hole_area=0,
)
ctx = SimpleNamespace(session=object())
result = vectoreyes_trace_drawing(options=options, ctx=ctx,
    image_data=DirectImageRef(path=str(Path("source.png").resolve())))
response = result.structured_content
artifact = vectoreyes_get_drawing_artifact(response["drawing_id"], "v0", "svg", ctx)
Path("result.svg").write_text(artifact.structured_content["svg"])
```

Run with `VECTOREYES_MCP_TRANSPORT=stdio` so local paths are trusted. Alternatively
pass the actual PNG bytes as base64 in `DirectImageRef`, avoiding filesystem trust.
This process has its own in-memory drawing store; its IDs are not live in the
deployed server and disappear on exit. The exported file remains usable.

These are diagnostic fallback choices, not universal defaults: retaining tiny
regions can retain noise, and disabling symmetry forfeits useful cleanup.
Render and inspect the SVG before delivery. Report that MCP failed and that
the file was generated by the direct converter. It cannot be refined with
`vectoreyes_refine_drawing` without a separately successful trace.

A faithful preview is not proof of a fabrication-ready file. For Cricut or
single-color cutting, check transparent cutouts, closed paths, unwanted white
overlays/gradients, minimum feature sizes, and cutting scale. Do not promise
cut readiness based on the rendered preview alone.
